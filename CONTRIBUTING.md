# Contributing

Thank you for your interest in Culla.

## Issues are welcome

- **Bugs:** open an issue with what you did, what you expected, what happened, your Windows version and the Culla version or commit. If a photo file triggers it, say so, but do not attach your photos to a public issue: they can contain GPS data.
- **Ideas:** open an issue describing the problem first, then the idea. Scope is kept small on purpose ([PRD](docs/PRD.md), [roadmap](docs/roadmap.md)), so some good ideas will wait.
- **Security:** do not open a public issue. See [SECURITY.md](SECURITY.md).

## Pull requests

Outside pull requests are not merged for now, so Culla keeps a single author ([ADR 0026](docs/adr/0026-gpl-3-0-only-licence-and-reserved-name.md)). If you have a fix, describe it in an issue; it will be credited if it is used. This may open up later.
