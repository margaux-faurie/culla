# Name and logo

Culla's code is licensed under the [GNU GPL v3.0 only](LICENSE). The licence covers the code. It does not cover the name "Culla" or the Culla logo, which belong to Margaux Faurie.

## What you can do

- Fork, change and share Culla under the GPL. Give your version another name and its own logo.
- Say that your project is based on Culla, or works with it, in plain text ("based on Culla").
- Write about Culla, review it, or teach with it, using the name and unmodified logo to refer to this project.
- Share unmodified copies of an official Culla release under its own name.

## What needs permission

- Calling a modified version "Culla", or using a name or logo that could be confused with it.
- Using the name or logo in a way that suggests Margaux Faurie made, endorses or supports your version.
- Using the name or logo for a product, service or domain name.

To ask, open an issue in this repository.

The name is not a registered trademark yet. This page states how the author asks it to be used.
